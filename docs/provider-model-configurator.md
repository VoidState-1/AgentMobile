# 供应商与模型配置器：需求拆解

日期：2026-10-13。状态：P0 已实现，代码、浏览器和 Android 模拟验收通过；用户确认本轮 Anthropic/Gemini 先完成实现和模拟验证，官方服务实测待提供凭证。第 12 节记录交付范围。

## 1. 目标与当前差距

用户能保存多个模型服务连接，为每个连接管理多个模型，在会话中快速选择模型，并知道所选配置能否完成当前任务。配置器负责连接、凭证、模型能力和运行参数，Agent 执行器消费明确的配置结果。

实施前的基线只有一份全局 ModelSettings、一枚固定存储键名的 API Key、DeepSeek 预设、手工模型 ID 与 /models 检测。传输只有 Chat Completions；任务没有配置快照，界面与执行生命周期耦合。以下章节保留需求和设计依据，当前实现见第 12 节。

本轮协议范围已确定：完善 Chat Completions 兼容协议，同时接入 Anthropic Messages 和 Gemini 原生协议。预设覆盖 DeepSeek、Anthropic、Gemini，并支持选择上述协议的自定义服务。每种协议实际实现认证、消息、图片、工具与流式传输。

## 2. 三类核心对象

| 对象 | 内容 | 示例 |
| --- | --- | --- |
| 供应商预设 ProviderPreset | 默认地址、协议/兼容特性、认证方式、可用参数、模型资料的来源与版本 | DeepSeek 官方预设 |
| 服务连接 ProviderConnection | 稳定 ID、用户命名、预设引用、实际地址、协议、凭证引用、启用状态、最近检测结果 | DeepSeek · 个人、DeepSeek · 工作、我的中转服务 |
| 模型配置 ModelEntry | 稳定 ID、所属连接、请求使用的模型 ID、显示名、能力、默认参数、收藏与可用状态 | 个人连接下的 deepseek-flash |

同一供应商可有多份连接；同名模型在不同连接中是不同可选项。运行时选中 ModelEntry 后，能明确解析出连接、凭证和参数。供应商品牌与请求协议分别记录，兼容服务可保留其实际服务名称。

演示模式作为独立运行选项保留。

## 3. 本轮推荐范围

### P0：可实际使用的配置器

1. **多连接管理**：添加、编辑、命名、启停、复制、删除；DeepSeek、Anthropic、Gemini 预设和自定义服务。复制连接默认产生需要填写凭证的新连接。
2. **独立凭证**：每份连接有独立凭证引用，支持填写、替换、删除和缺失状态；编辑普通字段不要求重新填写已有密钥。
3. **模型管理**：发现模型、搜索、添加手工模型、修改显示名、收藏、启停、删除。发现接口不可用时仍能手工配置。
4. **能力与参数**：展示工具、图片、思考等能力及其依据；配置适配器实际支持的输出上限、温度等基础参数。不可生效的选项明确说明状态。
5. **分层检测**：字段校验、服务连接、指定模型生成、工具能力和图片能力分别展示结果；允许保存尚未实测的配置。
6. **模型选择**：全局默认、项目默认、会话选择；输入区展示连接名与模型名，支持快速切换与收藏筛选。
7. **运行绑定**：任务启动时冻结配置，记录供应商、模型、参数与配置版本；后续编辑影响新任务。
8. **迁移与失败恢复**：已有单配置和密钥迁入新结构；保存失败不损坏原配置，历史任务继续可读。
9. **三协议实际适配**：Chat Completions、Anthropic Messages、Gemini 原生各自完成文字、图片、工具循环、流式生成、取消和诊断。

### P1：进一步完善

- Responses 等其他新增协议的真实适配与验证。
- 思考模式、思考强度及其跨工具轮次上下文传递；当前 DeepSeek 适配器只有 off。
- 参数预设，例如同模型的日常、长文配置。
- 配置导入导出，剔除凭证与敏感 Header；包含格式版本和兼容检查。
- 有来源和更新时间的上下文长度、输出限制、价格资料，以及用户覆盖值。
- 更丰富的认证、供应商额外字段、Header 与受约束的扩展参数。

端侧模型执行、自动供应商故障切换、密钥轮询、余额充值、账单系统、跨设备密钥同步和自定义适配器脚本属于后续独立需求。

## 4. 供应商连接规则

- 用户先选择预设或自定义连接，再填写地址、认证方式和凭证。首轮覆盖三种协议需要的 API Key 认证与自定义兼容服务的无需认证方式，由适配器管理实际 Header、版本字段等差异。
- 地址在保存时校验并规范化，保留自定义兼容网关的必要路径；实际请求 URL 和认证目标应可确认。
- 凭证绑定服务连接及目标 Origin。更换目标服务时进入需要重新绑定凭证的状态，同一 Origin 的路径调整保留已有绑定。
- 连接检测可以取消，超时有明确结果；保存、检测、启用是独立操作。
- 删除或禁用前显示受影响的默认选择；历史任务保留当时的配置信息。运行中被使用的凭证不能提前清理。
- 首轮以 HTTPS 和本机开发地址为基线。局域网 HTTP 服务的地址、明文认证与移动网络权限单独确定。

### 三种协议的适配边界

| 协议 | 配置与发现 | 运行适配 |
| --- | --- | --- |
| Chat Completions 兼容 | Bearer/可选无需认证、服务模型目录和手工 ID、显式兼容特性 | 消息与工具 schema、图片编码、SSE delta、结束原因和用量 |
| Anthropic Messages | 原生 API Key 认证、版本字段、官方目录和手工 ID | system/messages 差异、图片块、tool_use/tool_result、内容块流与用量 |
| Gemini 原生 | 原生 API Key 认证、官方模型名称与分页目录、生成能力筛选 | contents/parts、函数调用与返回、图片数据、流式候选结果和用量 |

一个连接确定一套通信协议。同一网关提供多个协议时，可创建分别命名的连接。模型目录中的 ID/资源名称由对应适配器解释，用户显示名不影响请求。

三种协议归一化为 Pi Agent Core 能消费的消息与事件，传输留在平台适配层。需要回传的工具关联信息、签名或其他协议元信息应完整保留；思考开关关闭也不能省略供应商要求的协议数据。跨协议切换保留可见文字上下文，原协议的私有元信息按兼容策略处理。

流解析必须处理工具参数分片、多个调用、正常结束、服务流内错误与中途取消。功能验证覆盖原生工具循环和图片输入，不能用一个文本生成成功替代整个协议验收。

Android/iOS 和浏览器分别记录检测结果。浏览器的跨域限制或服务要求的直连标记由对应适配器处理；浏览器连接失败不能被解释为原生客户端不可用。OAuth、云平台服务账号和企业托管认证属于后续范围，首轮采用 API Key。

## 5. 模型发现与能力

### 模型目录

- 从服务发现 API 获取可调用 ID，支持搜索、收藏、已启用筛选与手工添加。
- 缓存发现结果，显示获取时间；断网仍可浏览和编辑已有配置。
- 刷新合并新模型，保留用户命名、收藏、参数与覆盖值。
- 列表中消失的模型标记最近未发现，保留已有配置和引用；不自动换成另一个模型。
- 不要求发现 API 提供能力、价格或上下文长度，这些字段采用独立来源。
- 较大目录采用虚拟列表，保持手机上的紧凑行布局与可操作触摸区域。

### 能力依据

工具调用、图片输入和思考分别记录“支持 / 不支持 / 未知”，并记录资料来源：预设资料、用户声明、实测结果及其时间。

“验证失败”单独记录原因。鉴权、余额、超时或格式错误不能直接解释为某项能力不支持。连接、协议或模型身份变化后，相关检测结果失效。

实际可用选项同时受模型能力、适配器实现和用户开关约束。明确不支持工具调用的模型无法用于工作区 Agent；未知能力允许配置和按需验证，界面保留未验证标识。图片能力未知或不可用时，发送前给出明确处理选择，不默默遗漏图片。

所有运行参数必须由适配器声明、校验并真正进入请求。不根据域名或模型 ID 字符串猜测能力；预设兼容特性采用显式配置。参数恢复默认只影响当前模型配置的参数。

## 6. 检测结果的含义

| 检测 | 验证内容 | 请求范围 |
| --- | --- | --- |
| 本地校验 | 地址、必需字段、参数范围、协议实现存在 | 无网络请求 |
| 服务连接 / 模型目录 | 服务可达、认证结果、所选模型是否被发现 | 发现/鉴权请求，不生成内容 |
| 文本生成 | 指定模型实际返回完整内容 | 小型生成请求，可能计费 |
| 工具验证 | 完整工具调用、宿主返回结果、模型继续生成 | 内置无副作用测试工具，可能计费 |
| 图片验证 | 模型读取图片并返回可核对的结果 | 内置合成测试图，可能计费 |

每项保存状态、时间、错误分类和检测配置版本。检测使用内置样本，不读取用户工作区。生成测试按钮明确标注费用属性，限制请求数、输出和超时；不会因打开设置而自动进行生成测试。

原始服务响应、请求 Header 和密钥不进入公开日志。诊断信息区分地址、认证、模型、余额、限流、协议、网络与浏览器跨域问题。

## 7. 默认选择与运行规则

推荐优先级：**会话明确选择 > 项目默认 > 全局默认**。没有可用默认时引导添加或选择配置，保留用户输入。

- 修改全局默认不覆盖已有明确选择的项目或会话。
- 启动任务时解析并冻结 ResolvedRunConfig：连接/模型 ID、公开显示信息、协议与兼容设置、实际参数、配置版本。凭证原文不进入持久化快照。
- 一次任务的后续模型轮次继续使用启动时的配置。供应商编辑、默认切换与目录刷新都不能改变该任务。
- 配置界面打开、关闭、切路由不应中断任务；Agent 运行生命周期与界面生命周期分离。
- 会话切换模型后，下一次请求按明确策略保留文本上下文，重新读取需要的文件，不重放旧工具调用。界面显示下一次请求将使用的服务；思考内容遵守对应协议的要求。
- 密钥缺失、连接禁用或模型不可用时，发送前给出具体原因；不隐式改用其他服务，也不自动重试有副作用的任务。
- 历史任务显示当时所用配置，旧任务无法确定的字段标为未知，不能根据当前默认补填。

## 8. 移动端界面建议

入口为“设置 → 模型与供应商”。核心编辑采用独立完整页面，深浅主题沿用当前工作台。

1. **供应商列表**：名称、服务地址摘要、模型数量、凭证/启用状态，顶部添加操作。
2. **供应商详情**：连接编辑、检测结果与模型列表，支持手工添加和刷新目录。
3. **模型详情**：显示名和请求 ID、能力依据、可用参数、独立检测、收藏/默认操作。
4. **会话模型选择器**：紧凑可搜索面板，先展示收藏与最近使用，行内标识所属连接和关键能力。

已保存凭证通常显示状态和遮罩，替换时再输入新值。编辑具有草稿、保存、取消及未保存保护；字段错误定位到对应输入。启用、检测和默认等状态有明确名称，避免一个“已连接”标识包办所有含义。

## 9. 数据与实现分工

- src/core/models：领域实体、配置解析、默认优先级、能力与参数约束、仓库和凭证接口。
- src/adapters/model：协议适配器、预设/目录读取、检测、实际参数映射与错误归一化。
- src/adapters/storage：SQLite 配置与检测元数据、按引用保存的 SecureStore 凭证；浏览器凭证采用会话内映射。
- src/features/model-config：配置页面与选择器；Zustand 仅承载界面状态。

配置与检测元数据保存在 SQLite，不写入项目 Git，不向 Agent 或未来动态 UI 暴露凭证管理接口。每个持久对象使用稳定 ID 和配置版本。

SQLite 与 SecureStore 无跨存储事务。新凭证引用的创建、配置保存和旧凭证清理需要可恢复顺序；保存失败时原引用仍可使用。应用重启应修复未完成迁移或孤立引用，不能静默丢弃有效配置。

迁移现有全局设置时，建立默认连接与模型，转移凭证引用，验证成功后完成迁移。迁移可重复执行，并兼容浏览器重开后需要补填凭证的状态。

## 10. 验收与实施顺序

验收至少覆盖：

- 同时保存两份同供应商连接及多个模型，修改或删除其中一个不会串用另一份密钥。
- 无发现接口、断网、模型目录变化、缺失凭证和部分参数未知时仍有清楚的处理路径。
- 工具与图片能力的声明、检测和请求行为一致，未实现选项不会被当作已经生效。
- 切默认/编辑参数时，运行中的任务继续原配置；历史仍能显示当时模型。
- 打开配置页面不取消任务，保存失败不破坏原配置，迁移与重启保留可用配置。
- 密钥不出现在 SQLite、任务、项目文件、导出、日志或构建产物中。
- DeepSeek、Anthropic、Gemini 各验证一条真实文字/工具闭环和可用模型的图片路径，另验证自定义兼容端点；截图检查手机深浅主题和键盘操作。

实施顺序：**数据模型与迁移 → 协议注册与三种适配器 → 多连接/模型管理界面 → 模型发现和分层检测 → 会话选择与运行快照 → 各协议真实服务及原生回归**。三种适配器分别验收，能力实测后更新模型配置中的验证状态。

P0 已实现：

- 独立凭证引用、缺失/替换/移除；SQLite 图配置原子保存，SecureStore 新引用先写、图提交后清理旧引用，运行租约延后回收。浏览器凭证仅在页面内存。
- 模型分页发现与刷新合并、目录消失标识、手工添加、命名、收藏、启停、搜索和删除；模型列表使用 FlatList。
- 能力三态及预设/目录/用户/实测来源；输出上限、温度、图片授权实际映射进请求。思考控制仍为 P1：DeepSeek 显式关闭思考，其他服务遵循供应商默认，快照记录有效策略。
- 三协议原生认证、文字、图片、工具循环、SSE、用量、取消、结束校验。Anthropic thinking/signature/redacted blocks 和 Gemini 原始 parts/thoughtSignature/工具关联按原协议保留。
- 目录检测与独立文本/工具/图片检测；使用无副作用样本，生成测试显式标为可能计费，最多 2 次生成、128 输出 tokens、30 秒，不访问工作区。网络/鉴权/余额/限流/格式失败不改写为能力不支持。
- 全局默认、项目默认和会话选择；会话选择器支持收藏、最近使用排序和搜索。停用或删除的明确选择阻止发送，草稿保留，不静默选用其他连接。
- 任务启动时冻结公开配置快照，密钥保留在宿主租约；打开配置、修改参数和密钥不改变运行任务。历史任务显示当时连接与模型，旧任务标记未知。
- 完整配置页面、深浅主题、固定保存区、键盘避让、离开/刷新未保存保护。配置和运行生命周期已分离。

实施位置：src/core/models（实体/规则/迁移/服务）、src/adapters/model（三协议/目录/检测）、src/adapters/agent/task-manager.ts（执行所有权）、src/features/model-config（页面/选择器）。

已通过的验证与原生进度详见 [validation.md](validation.md)。官方 Anthropic/Gemini 凭证暂不可用，本轮未执行这些供应商的真实付费调用。模拟验证证明协议组装、解析和宿主闭环，官方模型、账号权限、服务限额与实际网络仍需实测。

仍未实现：Responses、思考强度控制、导入导出配置、额外 Header/OAuth/云服务账号、局域网 HTTP、价格与精确 token 预算、后台常驻、任务自动续跑、跨设备同步。当前每个项目只有一个主会话，已预留会话 ID 的选择映射。
